## Kartu Rebus Game

Folder `rebus/` berisi 110 kartu puzzle original yang dibuat khusus untuk bot. Kartu ini mengikuti pola permainan tebak gambar: beberapa ilustrasi digabung untuk membentuk kata atau frasa, tanpa menyalin screenshot atau aset dari aplikasi Google Play.

## Koleksi Tambahan

Folder `library/` berisi 127 thumbnail berukuran kecil dari kategori hewan, makanan, kendaraan, benda, dan tempat di Wikimedia Commons. Koleksi ini diambil melalui API kategori Commons dan dipakai sebagai soal acak; nama file menyimpan kategori jawaban, misalnya `kucing-01.jpg` menjadi jawaban `KUCING`.
